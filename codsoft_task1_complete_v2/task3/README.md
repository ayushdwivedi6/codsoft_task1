# Calculator — CodeSoft Internship Task

A basic responsive calculator built using HTML, CSS and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear (AC)
- Delete (DEL)
- Division-by-zero error handling
- Keyboard support
- Responsive CSS Grid layout

## Technologies

- HTML5
- CSS3
- JavaScript

## How to run

Open `index.html` in a browser or use VS Code Live Server.
