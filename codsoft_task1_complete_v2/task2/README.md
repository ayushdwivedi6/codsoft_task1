# Nextora Landing Page — CodeSoft Internship

A responsive business landing page created as a beginner-friendly HTML/CSS web development project for the CodeSoft internship.

## Features

- Responsive navigation
- Hero section inspired by the provided reference design
- Call-to-action buttons
- Trusted brands section
- Statistics section
- Services cards
- Project CTA banner
- Blog section
- Pricing section
- Responsive footer
- Mobile hamburger menu
- Responsive layout for desktop, tablet and mobile

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## How to run

Open `index.html` directly in a browser, or use VS Code Live Server.
